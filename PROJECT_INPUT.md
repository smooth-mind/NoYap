# Project Input

This file preserves the original project information and the evidence behind later requirements. It may begin as rough notes.

## How agents must use this file

- Do not write application code during input discovery.
- Preserve the user's original meaning.
- Do not silently improve an idea into a different product.
- Mark every material statement as Confirmed, Proposed, Open, Rejected, or Observed.
- Cite the source document, section, page, file, or user answer when possible.
- Ask only questions whose answers materially affect the project.
