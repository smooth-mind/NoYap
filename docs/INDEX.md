## Documentation categories

Create only categories the project needs:

- setup and local development;
- repository structure;
- modules;
- public APIs;
- database and migrations;
- deployment and operations;
- troubleshooting;
- user or administrator guides.

Each important module document should state its purpose, main files, interfaces, dependencies, data flow, limitations, related requirements, and tests.
