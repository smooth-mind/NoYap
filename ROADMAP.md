# NoYap Product Roadmap

This roadmap is for the NoYap open-source project itself. Projects created with NoYap use `noyap/PHASES.md` for their own roadmap.

## v0.1: Working template

- [x] Beginner onboarding from idea, SRS, or existing codebase
- [x] Core governance documents
- [x] Hybrid full roadmap plus rolling next prompt
- [x] Architecture, scope, stack, design, and security gates
- [x] Minimal-change protocol
- [x] Durable memory and current project state
- [x] Zero-dependency validator
- [x] Claude Code and GitHub Copilot routing adapters

## v0.2: Real-project validation

- [ ] Test on a small website built by a non-technical user
- [ ] Test on an existing codebase
- [ ] Publish before-and-after case studies
- [ ] Measure context size, drift, changed files, human corrections, and handoff success
- [ ] Simplify any step that does not prove useful

## v0.3: Better local tooling

- [ ] Initialize or reset a NoYap project safely
- [ ] Generate task-specific context lists
- [ ] Create and move change requests and ADRs
- [ ] Detect controlled-file changes from Git diffs
- [ ] Archive completed prompts automatically

## v0.4: Agent adapters and CI

- [ ] Add verified adapters for more agent tools
- [ ] Add configurable change budgets
- [ ] Add requirement-to-phase traceability checks
- [ ] Add optional pull-request governance summaries

## Not a current goal

NoYap should not become a large autonomous multi-agent framework, a replacement for issue tracking, or a requirement to write extensive documentation for trivial projects.
