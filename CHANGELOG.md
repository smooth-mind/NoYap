# Changelog

All notable changes to NoYap will be recorded here.

## 0.1.1 - 2026-07-26

### Fixed

- Validate the canonical current phase against the single Active phase
- Reject invalid project-state dates and invalid approval dates
- Reject unsupported baseline status values
- Validate `PROMPTS.md` front matter and its update date
- Prevent canonical project state from being duplicated in `PROMPTS.md`
- Preserve controlled-change directories in Git
- Add targeted negative-path tests for validator integrity
- Correct release text-file formatting

## 0.1.0 - 2026-07-25

### Added

- Beginner routes for rough ideas, SRS documents, and existing codebases
- Core governance templates
- Architecture, scope, dependency, design, and phase protection rules
- Hybrid roadmap plus rolling next-prompt workflow
- Guided, balanced, and autonomous modes
- Durable memory and concise project state
- Change request, ADR, phase, task prompt, and handoff templates
- Zero-dependency validation, status, and next-prompt commands
- GitHub Actions validation
- Short Claude Code and GitHub Copilot adapters
